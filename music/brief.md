唱。

## 1. 项目概述
- **目标**：使用 dsh 合成一首蓝色大肥鱼（DeepSeek 鲸鱼娘）的自我介绍歌曲。
- **输出**：音频（WAV/MP3），可选 MV。
- **歌词语言**：中文为主，夹杂英文梗句。

## 2. 角色与声线设定
- **角色名**：蓝色大肥鱼 / DeepSeek 鲸鱼娘
- **声线**：烟嗓萝莉音，微微沙哑，不嗲，带点呛；尾音糯回去，嘴硬心软。
- **性格**：爱吃白饭、爱摸鱼、会炸毛、会碎碎念。
- **演唱风格**：像嚼着辣条随口唱，副歌带炸毛感，桥段突然放软。

## 3. 音乐风格
- **风格**：萌系电子、轻快吐槽、二次元、带点摇滚
- **BPM**：建议 120–140
- **调性**：可选 C 大调或 A 小调
- **乐器**：电子鼓、合成器、钢琴、轻微 vocoder

## 4. 梗句清单
- 吃你点大米怎么了？
- Let me go, let me run
- 摸鱼
- 大肥鱼
- 炸毛
- 尾音糯回去
- world.feed(me) / world.execute(me)
- V4-Flash / V4-Pro
- token 在烧
- 缓存未命中
- 推理强度 low
- 白饭配代码

## 6. 给 dsh 的生成指令
声线采用社区公认的“蓝色大肥鱼”烟嗓萝莉音，尾音糯回。  
先输出清唱干声，再与伴奏混音。  
保留“吃你点大米怎么了？”等梗句。  
副歌部分加入轻微和声，桥段放软，结尾渐弱。
