## 二、整句核对（LRC 到底对不对得上）

咬字含糊是唱歌的正常现象，真正要盯的是**每一句有没有落在正确的时间点**。
`scripts/audit_lrc.py` 把这件事拆成两个可证伪的问题：

### 2.1 时间轴有没有整体偏

把整份歌词对音频做全局偏移扫描，看哪个偏移的总相似度最高：

```
offset      mean sim
 -0.5s        0.561
 +0.0s        0.727      ← 最佳
 +0.5s        0.523
```

**最佳偏移 +0.0 秒**，两侧都明显更差。说明 LRC 时间轴准确，
剩下的不一致来自咬字，不是字幕位置。

### 2.2 每一句有没有放错地方

逐行算出：① 该时间点实际听到的与歌词的相似度（本地）；② 这句话在全曲最像的位置在哪（全局）。
两者差距大且本地很低的，就是**放错了位置**——这跟"唱糊了"是完全不同的毛病。

| | 修之前 | 修之后 |
|---|---|---|
| 有实测锚点的行 | 80 / 103 | **96 / 103** |
| 句子位置正确 | 86 / 103（83%） | **101 / 103（98%）** |
| 明显错位 | 3 | **0** |
| 弱匹配 | 14 | **2** |
| 全局最佳偏移 | +0.0s（相似 0.567） | +0.0s（相似 **0.727**） |

### 2.3 错在哪、怎么修的

真错位的是副歌第一遍的两句：

```
LRC 原本：  [51.23] 蓝色鲸鱼游啊游   [55.48] 摸完这鱼再上班
实际唱的：  [~47-52] 就是这两句
```

根因是**谐音**。Whisper 把「摸完这鱼再上班」听成「**挽着雨才伤败**」——
鱼/雨、上/伤 同音；「蓝色鲸鱼游啊游」听成「拉**蓝色金鱼**」——鲸/金 近音。
按汉字比，字符重合度太低，匹配器不认这两行，它们只好被插值到后面的空隙里，晚了 4–9 秒。

**修法是按拼音比，不是按汉字比。** 装 `pypinyin`，让相似度取
「字形比」和「拼音比」的较大值，词级匹配也改成按拼音判等：

```
炸毛 / 扎毛       -> zhamao == zhamao     ✓
大肥鱼 / 大飞鱼    -> dafeiyu == dafeiyu   ✓
圆 / 远           -> yuan == yuan         ✓
```

改完之后这两行落到 **48.91s / 50.84s**，全曲 98% 的句子位置正确。

**这条对中文歌曲是通用的**——中文唱词的 ASR 错误绝大多数是同音字，
按字形比会系统性地丢掉锚点。

## 五、踩到的坑

### 5.1 重复回路
第一次用 900+ 字生成时，模型从 61 秒开始卡进退化循环，同一组句子连唱四遍，后半段全丢。
**`repetition_penalty` 从 1.2 提到 1.35 就消了。歌词越长越容易触发。**

### 5.2 近重复行也会触发回路
结尾那版有「记得带大米 不然我也炸毛」和「明天见 记得带大米」两句近似，
结果 190–208 秒把 Outro 循环唱了三遍。**删掉其中一句就好了。**
改词之后值得自查有没有近似重复的句子。

### 5.3 中文文件名
ComfyUI 输出文件用中文名时，PowerShell 管道读到的文件名会乱码，`Copy-Item` 找不到。
**`KMN_TITLE` 一律用 ASCII**，中文标题只写进 LRC 的 `[ti:]`。

## 六、旋律与和声

风格提示里我定框架，模型落实成具体走向：

- 框架：`mellow seventh and ninth chords, ii-V-I progressions, A minor, 100 BPM`
- 实际产出（`和弦谱.abc`）：**K:D，`Q:1/4=99`，4/4**

```
% verse
V: Vocal
"Dmaj7"f2fefefefef2a2f2ed|"Gmaj7"edededede2a2e2ed|"Em7"edededede2ededed|"A7"ededededf2ed2dd|
```

即 **| Dmaj7 | Gmaj7 | Em7 | A7 |** —— **I–IV–ii–V**，爵士最经典的 turnaround，四个和弦全是七和弦。
模型选了 D 大调而非我提示的 A 小调，走向本身没问题，就没纠。

## 七、时长怎么算

YuE2 纯生成路线的**歌长由歌词量决定**（约 3.9 字/秒）：

| 版本 | 歌词量 | 时长 |
|---|---|---|
| 电子版 | 605 字 | 154.4s |
| 爵士版（同歌词换风格 100BPM） | 605 字 | 175.8s |
| 爵士 + 扩写 | 851 字 | 231.0s |
| **爵士 + 扩写 + 加梗（交付）** | **945 字** | **268.4s** |

两个杠杆：**换慢风格约 +14%**，剩下靠加词。
`scripts/lyric_length.py` 会按中英文自动选速率，改词前先跑，别浪费一次生成。
